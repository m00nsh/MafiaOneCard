# 스킬 시스템 테스트 가이드 (Phase 1 & 2)

## 📋 테스트 전 준비사항

### 1. 서버 실행
```bash
# 프로젝트 루트에서
cd apps/backend
npm run dev
# 또는
pnpm dev
```

서버가 정상적으로 실행되면 `http://localhost:2567`에서 Colyseus 서버가 실행됩니다.

### 2. 프론트엔드 실행
```bash
# 새 터미널에서
cd apps/frontend
npm run dev
# 또는
pnpm dev
```

프론트엔드가 정상적으로 실행되면 `http://localhost:5173`에서 게임이 실행됩니다.

## 🧪 Phase 1 테스트: 기본 스킬 UI

### 테스트 1: 스킬 버튼 표시 확인

**목표**: 스킬 버튼이 올바르게 표시되는지 확인

**절차**:
1. 게임 시작 후 캐릭터 선택 화면에서 캐릭터 선택
2. 로비에서 "Ready" 버튼 클릭
3. 게임 시작 후 하단 우측에 스킬 버튼 확인

**예상 결과**:
- ✅ 스킬 버튼에 캐릭터 이름이 표시됨 (예: "잡상인 사용")
- ✅ 쿨타임 게이지 바가 표시됨
- ✅ 쿨타임이 0이면 버튼이 비활성화 상태 (회색)
- ✅ 쿨타임이 가득 차면 버튼이 활성화 상태 (보라색)

### 테스트 2: 쿨타임 게이지 확인

**목표**: 쿨타임이 턴마다 증가하는지 확인

**절차**:
1. 게임 시작 (쿨타임: 0/3)
2. 내 턴이 돌아올 때마다 쿨타임 게이지 확인
3. 쿨타임이 3/3이 되면 버튼 활성화 확인

**예상 결과**:
- ✅ 내 턴이 시작될 때마다 쿨타임이 1씩 증가
- ✅ 쿨타임 게이지 바가 점진적으로 채워짐
- ✅ 쿨타임이 최대치에 도달하면 버튼 활성화

### 테스트 3: 스킬 다이얼로그 표시

**목표**: 스킬 버튼 클릭 시 다이얼로그가 올바르게 표시되는지 확인

**절차**:
1. 쿨타임이 가득 찬 상태에서 스킬 버튼 클릭
2. 스킬 다이얼로그 확인

**예상 결과**:
- ✅ 스킬 다이얼로그가 열림
- ✅ 스킬 이름, 설명, 쿨타임 정보가 표시됨
- ✅ 현재 진행도가 표시됨 (쿨타임 기반 스킬)
- ✅ 남은 사용 횟수가 표시됨 (소환사, 광전사)

### 테스트 4: 사용 횟수 제한 스킬 (소환사, 광전사)

**목표**: 사용 횟수 기반 스킬이 올바르게 작동하는지 확인

**절차**:
1. 소환사 또는 광전사 캐릭터 선택
2. 게임 시작 후 스킬 버튼 확인
3. 스킬 사용 후 남은 사용 횟수 확인

**예상 결과**:
- ✅ 쿨타임 게이지 대신 "남은 사용: 2회" 표시
- ✅ 스킬 사용 후 사용 횟수가 감소
- ✅ 사용 횟수가 0이 되면 버튼 비활성화

## 🧪 Phase 2 테스트: 스킬별 특수 처리

### 테스트 5: 잡상인 스킬 (카드 + 플레이어 선택)

**목표**: 잡상인 스킬의 2단계 선택 프로세스 확인

**절차**:
1. 잡상인 캐릭터 선택
2. 쿨타임 충전 후 스킬 버튼 클릭
3. 스킬 다이얼로그에서 "스킬 사용" 버튼 클릭
4. 카드 선택 다이얼로그에서 카드 선택
5. 플레이어 선택 다이얼로그에서 대상 플레이어 선택

**예상 결과**:
- ✅ 카드 선택 다이얼로그가 먼저 열림
- ✅ 내 손패의 모든 카드가 표시됨
- ✅ 카드 선택 시 하이라이트 표시
- ✅ 카드 선택 후 플레이어 선택 다이얼로그가 자동으로 열림
- ✅ 플레이어 선택 후 스킬 사용 완료

### 테스트 6: 탱커 스킬 (공격 스택 필요)

**목표**: 탱커 스킬이 공격 스택이 있을 때만 사용 가능한지 확인

**절차**:
1. 탱커 캐릭터 선택
2. 게임 시작 후 쿨타임 충전
3. 공격 스택이 없는 상태에서 스킬 버튼 확인
4. 다른 플레이어가 공격 카드(A, 2, 조커) 사용
5. 공격 스택이 쌓인 상태에서 스킬 버튼 확인

**예상 결과**:
- ✅ 공격 스택이 없으면 스킬 버튼 비활성화 (또는 툴팁 표시)
- ✅ 공격 스택이 있으면 스킬 버튼 활성화
- ✅ 스킬 사용 시 공격 스택 2장 면제

### 테스트 7: 주술사 스킬 (플레이어 선택)

**목표**: 주술사 스킬의 플레이어 선택 기능 확인

**절차**:
1. 주술사 캐릭터 선택
2. 쿨타임 충전 후 스킬 버튼 클릭
3. 스킬 다이얼로그에서 "스킬 사용" 버튼 클릭
4. 플레이어 선택 다이얼로그에서 대상 플레이어 선택

**예상 결과**:
- ✅ 플레이어 선택 다이얼로그가 열림
- ✅ 모든 상대방 플레이어가 표시됨
- ✅ 플레이어 정보 (닉네임, 캐릭터, 카드 수) 표시
- ✅ 플레이어 선택 시 체크 표시
- ✅ 선택 완료 후 스킬 사용

### 테스트 8: 소환사 스킬 (플레이어 선택)

**목표**: 소환사 스킬의 플레이어 선택 기능 확인

**절차**:
1. 소환사 캐릭터 선택
2. 스킬 버튼 클릭 (사용 횟수 확인)
3. 플레이어 선택 다이얼로그에서 대상 플레이어 선택
4. 선택한 플레이어의 스킬 사용 확인

**예상 결과**:
- ✅ 플레이어 선택 다이얼로그가 열림
- ✅ 선택한 플레이어의 스킬이 사용됨
- ✅ 사용 횟수가 감소함

### 테스트 9: 암살자 스킬 (플레이어 선택)

**목표**: 암살자 스킬의 플레이어 선택 기능 확인

**절차**:
1. 암살자 캐릭터 선택
2. 쿨타임 충전 후 스킬 버튼 클릭
3. 플레이어 선택 다이얼로그에서 대상 플레이어 선택

**예상 결과**:
- ✅ 플레이어 선택 다이얼로그가 열림
- ✅ 선택한 플레이어가 카드 3장을 받음
- ✅ 토스트 알림 표시

### 테스트 10: 광전사 스킬 (플레이어 2명 선택)

**목표**: 광전사 스킬의 다중 플레이어 선택 기능 확인

**절차**:
1. 광전사 캐릭터 선택
2. 스킬 버튼 클릭
3. 플레이어 선택 다이얼로그에서 플레이어 2명 선택

**예상 결과**:
- ✅ 플레이어 선택 다이얼로그가 열림
- ✅ 플레이어 2명을 선택할 수 있음
- ✅ 선택된 플레이어 수가 표시됨 (1/2, 2/2)
- ✅ 2명 선택 완료 후 스킬 사용

**특수 케이스**: 2인 플레이
- ✅ 플레이어 1명만 선택 가능 (본인 제외)
- ✅ 선택 완료 후 스킬 사용

### 테스트 11: 도둑/예언자 스킬 (추가 입력 없음)

**목표**: 추가 입력이 없는 스킬이 즉시 사용되는지 확인

2. 쿨타임 충전 후 스킬 버튼 클릭
3. 스킬 다이얼로그에서 "스킬 사용" 버튼 클릭

**예상 결과**:
- ✅ 스킬 다이얼로그가 열림
- ✅ "스킬 사용" 버튼 클릭 시 즉시 스킬 사용
- ✅ 추가 선택 다이얼로그가 열리지 않음

## 🐛 문제 해결

### 문제 1: 스킬 버튼이 표시되지 않음

**원인**: 
- 캐릭터가 선택되지 않았거나
- 게임 상태가 PLAYING이 아님

**해결**:
1. 브라우저 콘솔에서 에러 확인
2. `gameState?.myPlayer?.characterId` 확인
3. `gameState?.status`가 "PLAYING"인지 확인

### 문제 2: 쿨타임이 증가하지 않음

**원인**:
- 서버에서 `skillProgress`가 업데이트되지 않음
- 턴 시작 시 쿨타임 업데이트 로직 문제

**해결**:
1. 서버 콘솔에서 `onTurnStart` 로그 확인
2. `gameState?.myPlayer?.skillProgress` 값 확인
3. 네트워크 탭에서 상태 동기화 메시지 확인

### 문제 3: 플레이어 선택 다이얼로그가 열리지 않음

**원인**:
- `players` Map이 비어있거나
- `myId`가 올바르지 않음

**해결**:
1. `gameState?.players` 확인
2. `myId` 값 확인
3. 브라우저 콘솔에서 에러 확인

### 문제 4: 스킬 사용 후 서버 응답 없음

**원인**:
- 메시지 타입 불일치
- 서버에서 스킬 처리 실패

**해결**:
1. 브라우저 콘솔에서 `use_skill` 메시지 전송 확인
2. 서버 콘솔에서 에러 확인
3. 네트워크 탭에서 WebSocket 메시지 확인

## 🎯 빠른 테스트 시나리오

**최소 테스트 (5분)**:
1. 게임 시작 → 잡상인 선택
2. Ready → 게임 시작
3. 쿨타임 충전 대기 (3턴)
4. 스킬 버튼 클릭 → 카드 선택 → 플레이어 선택

3. 피드백 및 알림 확인
4. 쿨타임 시스템 확인
